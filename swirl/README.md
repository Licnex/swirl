# Portfolio Website

This is a static portfolio website project that showcases the work and information of the portfolio owner. The website consists of three main pages: Home, About, and Contact.

## Project Structure

```
portfolio-website
├── index.html       # Main page of the portfolio site
├── about.html       # Information about the portfolio owner
├── contact.html     # Contact information page
├── css
│   └── styles.css   # Styles for the portfolio site
├── js
│   └── script.js    # JavaScript file for potential interactivity
├── assets
│   └── fonts        # Directory for custom fonts
└── README.md        # Documentation for the project
```

## Features

- **Responsive Design**: The website is designed to be responsive and accessible on various devices.
- **Unique Styling**: Each page has uniquely styled paragraphs to enhance readability and visual appeal.
- **Favicon**: A favicon is included for branding purposes.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser to view the main page.
3. Navigate to the About and Contact pages using the links provided in the footer.

## Technologies Used

- HTML5
- CSS3
- JavaScript (for potential interactivity)
