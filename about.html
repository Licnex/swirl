Sprong

Case Study · November 14, 2024

Overview

In this project, I made my own game inspired by classic Pong. The game was made to run on Sprig, a low-level game console, blending nostalgic mechanics with modern deployment.

Key Features

  • Multiplayer and Singleplayer capability: The game allows for both single player and multiplayer with the advent of a custom bot solely for pong.
  • Browser and Sprig compatibility: Thanks to the website of Sprig being able to run games directly on their website, you don't even need to own a Sprig to play.

Technologies Used

  • JavaScript: Since all Sprig games are made with JavaScript.
  • Sprig: For running the game.
  • GitHub Actions: For automating the pipeline and syncing design changes to the repository.

Challenges & Learnings

One of the biggest challenges was just removing and figuring out bugs. I fixed one bug, another one appeared. I am pretty sure I learned something about myself debugging the code.

Outcome

A fun and accessible game that brings the joy of Pong to new platforms.

Making a LineFollower

Case Study · April 8, 2024

Overview

Development of an advanced LineFollower using the PID algorithm, PCB, and many more technologies. An advanced line-following robot powered by precise control algorithms, custom circuit boards, and detailed documentation.

Key Features

  • PID: Implemented a Proportional-Integral-Derivative control algorithm to ensure precise and stable line following.
  • PCB: Designed custom printed circuit boards to integrate all components efficiently.
  • Documentation and Usage Guidelines: Developed comprehensive documentation so that anyone else may use the code or designs for ease.

Technologies Used

  • KiCad: For making good usable and flexible PCB boards.
  • PlatformIO IDE: For uploading code across the microcontroller easily.
  • QTR IR sensors: For a responsive and fast array of sensors.
  • ESP32-S3 WROOM 2: For a fast computation-wise microcontroller with the flexibility of having a WiFi and Bluetooth module to customize PID constants.
